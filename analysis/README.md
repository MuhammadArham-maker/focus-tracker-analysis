# Analysis workbook

`Focus_Tracker_Analysis.xlsx` is the cleaned public analysis workbook created from the downloaded Google Sheets export.

It retains the 79 session-level self-tracking records (including their form-submission timestamps) and includes formula-driven summary sheets. Empty export columns were removed. The workbook does not contain form editor or analytics URLs.

For field meanings and interpretation limits, see [`../docs/DATA_DICTIONARY.md`](../docs/DATA_DICTIONARY.md) and [`../docs/METHODOLOGY.md`](../docs/METHODOLOGY.md).
